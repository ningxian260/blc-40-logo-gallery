# 佛梁 4.0｜四十周年標誌方案

純靜態網站，無需安裝或建置。開啟 `index.html` 即可預覽。

## GitHub Pages 部署

1. 建立 GitHub repository，將此資料夾內所有檔案（包括 `assets`）上傳至 repository 根目錄。
2. 在 GitHub repository 的 **Settings → Pages**，選擇 **Deploy from a branch**，設定 `main` 分支及 `/ (root)`，然後儲存。
3. 等待 GitHub Pages 完成部署，從 Pages 設定頁取得網站網址。

圖片為提供的原始方案，網站使用相對路徑，支援 GitHub Pages 的 repository 子路徑。
